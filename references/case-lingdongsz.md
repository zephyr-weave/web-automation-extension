# 实战案例：蓝鲸选品自动导出插件（v1.0 → v1.5.0）

> 六步法的完整落地记录。新项目可对照此例理解每一步"做到什么程度算完"。

## 背景与目标

- 站点：蓝鲸选品网页版 `xp.lingdongsz(j).com`，Vue3 + Element Plus + vxe-table
- 需求：全自动完成「点导出当前页 → 弹窗选"显示」→ 等文件下载完成 → 点下一页 → 循环」，末页自动停止
- 形态：Chrome/Edge MV3 扩展 = content script（悬浮控制面板 + 主循环）+ background service worker（下载事件监视 + 安装时自动注入已打开页面）

## 第 1 步摸出现场（关键发现）

- 操作链：点「导出当前页下载」（工具栏图标按钮，title 可作稳定钩子）→ 300ms 后弹「是否显示图片」→ 点「显示」→ 100ms 下载开始、600ms 下载完成 → 分页器是 Element Plus `.el-pagination .btn-next`，末页时加 `is-disabled` + `disabled`
- **红线：30 秒内第 4 次导出弹算术验证码** → 默认设计为 12 秒/页的节奏
- 异常出口：站点红色 toast 文本含"网络/超时/失败"；浏览器离线有 offline 事件

## 第 2 步设计（主流程 + 异常表）

- 主循环：频率控制等待 → 点导出 → 验证码检测 → 弹窗选「显示」→ 等下载完成 → 计数 → 末页判定 → 翻页 → 等表格渲染
- 异常表落地为：元素找不到（超时提示手动拾取）、验证码（暂停交还用户）、离线/toast（立即暂停）、35 秒无下载（自动暂停）、翻页不前进（重试一次再停）、末页（播报完成回待机）
- 检测分层：`chrome.downloads` 事件为精确检测，「固定等待」为兜底（面板可切换）
- 状态机：待机/运行/已暂停三态，暂停保留现场可继续

## 第 3 步实现要点

- 三态：`state.running` / `state.paused` 双标志
- 每个动作有编号日志（① 已点击导出按钮 / ② 已选择「显示」/ ③ 导出完成 / ④ 已点击下一页），带时间戳
- 所有等待有上限，暂停标志可立即打断长等待
- 多策略元素识别：保存的选择器 → 文本匹配 → title/aria 匹配 → 图标 class 匹配 → 手动拾取兜底

## 第 4 步测试矩阵（9 个 jsdom 端到端，全绿）

冒烟（主循环 3 页）/ 暂停继续 / 验证码暂停 / 离线暂停 / 错误 toast 暂停 / 运行中关闭 / 重置按钮 / 拾取守卫 / 后台保活。仿真站点四要素齐：导出按钮响应+弹窗、分页器状态流转、下载事件流（fireDL 模拟 background 消息）。**单页循环实测约 5 秒 → 3 页测试超时预留 15 秒以上。**

## 第 5 步交付四件套

zip 安装包 / README（控件表+注意事项+更新日志）/ progress.md 续接档案 / 真机验证清单（最小化 10 分钟实测——测试环境无法模拟真实节流）

## 第 6 步迭代：v1.5.0 三项反馈的三层修复

| 反馈 | 归类 | 直接修 | 兜底 | 提示+回退 |
|---|---|---|---|---|
| 拾取元素后任务失效 | A 代码错 | isTrusted 守卫（合成点击放行） | 开始时自动退出拾取模式 | 选择器失效一次性提示+回退自动识别 |
| 最小化/切页面不工作 | B 平台机制 | 无声音频保活（有声豁免节流） | play 失败仅记日志不阻塞 | README 写明扬声器图标副作用与授权原理 |
| 缺重置按钮 | 功能新增 | 一键恢复全部默认设置+清空拾取 | 重置后面板可正常开始/暂停（有测试） | 日志逐项说明恢复了什么 |

**顺手加固（克制）**：只改了与反馈同路径的 `uniqueSelector`——稳定属性钩子 + `querySelectorAll` 唯一性校验，没借机重构其他部分。

## 可复用数字

- 单页循环 ≈ 5s（500ms 频率等待 + 800ms 验证码检测 + 1500ms 下拉菜单探测 + ~1s 弹窗下载 + 400ms 翻页 + 500ms 渲染等待）
- 静音 WAV：0.1s / 8kHz / 8bit / 单声道 / 零样本，data URI 约 1.1KB
- 默认节奏 12s/页 vs 红线 30s/3 次——留 1.5 倍余量
